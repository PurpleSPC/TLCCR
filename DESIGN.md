# Farm Journal design

The selected editorial design is the actual homepage at `/`, promoted November 10, 2026. The comparison routes and old prototype layout have been removed.

All public pages use `src/layouts/FarmLayout.astro`, `FarmHeader`, `FarmFooter`, and `FarmBrand`. Real logo links return to `/`. The shared layout supplies titles, descriptions, canonical URLs, social metadata, a skip link, and the accessible visit chooser.

The visual system uses cream (#fff9e9), farm green (#2b5138), barn red (#a3362e), gold (#edbd53), and sky blue (#326780). Headings use Fraunces; interface text uses DM Sans. Interior pages follow the same editorial spacing, square photographs, colored rules, green headings, and red calls to action. Mobile navigation uses a native disclosure with Escape support.

The homepage retains five slideshow photos, four expanding photo cards, the animal/education/legacy story cards, and the community section. All three popup visit choices use the same soft green. The footer reads: “It's the pets' house, we just pay the mortgage!”

Current review captures are in `review/site/`. Earlier exploration screenshots are preserved in `review/design-history/`; they are reference artifacts, not public routes. Original photos remain untouched.

This is a local preview. Inquiry forms remain client-only previews without delivery or persistence. No hosting, domain, or live WordPress changes have been made.
